# Modern Gentlemen — 90-design collection

The original 30 section concepts, 30 additional section concepts and 30 article
mockups are implemented as editable website layouts. Open **Admin → MG 90 Collection**
(`/admin/editorial-collection`) to search by number, title, subject or reference
principle. Each entry has its original reference image and live desktop/mobile previews.

## Use a design

- Choose **Use this design**, enter a title and URL slug, and create a draft.
  Section designs create a page; article designs create a complete article with
  the paired presentation and editable body structure already selected.
- On an existing page or category, search **MG 90 collection** in **Add a section**.
  Designs 01–60 work in the Original and Canvas builders.
- On an existing article, choose a numbered collection design in **Article design**.
  Its matching **MG NN · [name] · Article body** is available in **Compose sections**.
  All 90 blocks are also available to article/template compositions.
- Native HTML Studio links to the collection. Its coordinate-based templates keep
  their existing data model; these layouts use the website's shared block system.
- Edit copy, media, captions, destinations, related stories, facts and chapter
  order using the normal property controls. Save, preview and publish normally.

Drafts contain writing prompts and chapter headings. Illustrative preview media and
reference mockup screenshots are never inserted into public documents. No existing
published page or article is automatically overwritten.

## Design and behavior

Ivory/charcoal surfaces, expressive serif headlines, fine rules, restrained red
accents and generous photography translate the researched editorial principles
into responsive native components. The reference sources are inspiration, not
partnerships or copied site templates. Live sample photography is clearly illustrative.

Layouts include magazine covers, interviews, guides, indexes, grids, reading lists,
comparison tables, newsletters, diaries, itineraries and reference dossiers. Where
appropriate, authored categories filter the cards; material buttons change details;
questions expand with keyboard support; chapters link to unique anchors. Media
plays on demand, with an editable captions URL for videos. The newsletter uses the
existing subscription endpoint. Related stories and actions use authored destinations.

The gallery is authenticated and permission-aware. Draft creation uses existing
permission checks, session clients and RLS, and saves each complete starter atomically.
No migration, new dependency, production content write or hosting change is needed.
The previous 29 article presentation choices and 24 signature sections remain available.

## Verification

All 90 manifests are checked through creation, editable values, serialization,
publish validation, media discovery and rendering. Native browser review covers
1440px and 390px, both color modes, accessible contrast and overflow. CI also
creates a page through the gallery, inserts all 60 sections, edits in both builders,
saves/reopens/publishes and checks anonymous output. A second journey creates and
publishes a complete article. Existing Appearance Studio tests now exercise all
59 presentation choices. Hosted CI is the production build, database, regression,
visual, accessibility and performance gate; current results are recorded on the PR.

The collection adds 90 optimized reference WebPs (about 14.4 MiB total), loaded in
an 18-item paginated admin gallery. Published layouts use authored media, never
these reference screenshots. Layout code and styles are scoped to the new collection.
